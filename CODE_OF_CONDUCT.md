# Code of conduct

Octopus follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work.
Harassment, personal attacks and discrimination are not tolerated in issues, pull requests or any other project space.

Report unacceptable behavior privately to the maintainers through [GitHub's private reporting](https://github.com/toovinod/octopus/security/advisories/new), marking it as a conduct report.
Maintainers will review every report and may warn, suspend or ban anyone who breaks this code.
